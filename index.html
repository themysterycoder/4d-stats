4D Number Stats

Read this first

Every 4D draw is independent. A "hot" number is no more likely next draw, and a "cold" one isn't "due". The stats below describe history, and the uniformity tests show whether that history looks any different from pure chance. The prize tables show that each $1 bet returns well under $1 on average.
